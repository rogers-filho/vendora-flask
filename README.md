# Vendora

Plataforma de e-commerce desenvolvida com Flask, SQLAlchemy e MySQL.
O desenvolvimento dessa plataforma é para o trabalho da disciplina de Frameworks para Desenvolvimento de Software, 4º Termo, Faculdade Antônio Eufrásio de Toledo - Presidente Prudente-SP.

## Tecnologias

- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy
- MySQL

## Funcionalidades

- Cadastro de usuários
- Endereços
- Anúncios
- Categorias
- Perguntas e respostas
- Compras
- Favoritos
- Relatório de compras
- Relatório de vendas
