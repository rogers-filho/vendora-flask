# Vendora

Plataforma de e-commerce desenvolvida com Flask, SQLAlchemy e MySQL.

## Tecnologias

- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy
- MySQL

## Funcionalidades

- Cadastro de usuários
- Endereços
- Anúncios
- Categorias
- Perguntas e respostas
- Compras
- Favoritos
- Relatório de compras
- Relatório de vendas
